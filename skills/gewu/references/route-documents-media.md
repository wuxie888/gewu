# 文档、图片与媒体路线

适用于本地或在线 PDF、办公文档、报告、论文、截图、图片、音频、视频和嵌入媒体。

## PDF、报告和论文

- 使用文档或 PDF 能力确认文件可读、页数、版本、作者和发布日期
- 用户要求完整阅读时逐页检查；无法逐页时准确记录页码范围
- 检查图表、注释、脚注、附录和方法限制，不用正文摘要替代
- 区分摘要、作者结论、数据证据与自己的推断
- 在线链接最终下载 PDF 时，按 PDF 路线处理，而不是强制在网页浏览器中完成

## 截图、图片、Logo 和界面

- 先进行整体视觉观察，再放大关键区域和做文字提取
- 记录界面结构、Logo、独特文案、域名片段、版本、命令和时间线
- 区分真实界面截图、概念稿、营销合成图和生成图
- 多张图片分别检查；长图不能只看缩略图
- 来源不明时进入来源反查，但不得借此识别普通人的敏感个人信息

## 视频与音频

- 确认时长、可播放范围、字幕可靠性和是否为核心证据
- 结论依赖媒体时检查完整内容或可靠完整字幕，并记录关键时间点
- 区分完整观看、片段检查、只看字幕和只看封面
- 无法播放、无可靠字幕或受限时列为未验证
- 不用视频旁边的宣传文案替代媒体内容

## 组合材料

文档内的链接、视频里的产品名或截图中的仓库线索，找到后切换到对应仓库或网页路线。各材料覆盖状态分别记录，不因其中一个来源完整就把整个证据链写成完整。
