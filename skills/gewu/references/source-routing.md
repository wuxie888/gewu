# 来源路由索引

先识别最终内容形态，再选择载体和详细路线。短链接、分享页或搜索结果的外观不能决定路线；一个任务包含多种材料时组合使用，但只加载匹配的详细文档。

| 内容形态 | 首选能力 | 详细路线 |
| --- | --- | --- |
| GitHub、GitLab、源码包、代码项目 | 仓库元数据、源码与只读检查 | [route-repositories.md](route-repositories.md) |
| 产品网站、在线工具、文章、社交帖子、微信公众号 | 用户指定或当前合适的页面级浏览载体 | [route-web-pages.md](route-web-pages.md) |
| 本地/在线 PDF、文档、截图、图片、音频、视频 | 对应文档、图像或媒体工具 | [route-documents-media.md](route-documents-media.md) |
| 名称、Logo、裁切截图、零散线索 | 先观察与提取，再进行来源反查 | [origin-tracing.md](origin-tracing.md) |

## 选择原则

- 需要视觉、布局或交互证据时，文本抽取、API、CLI 和搜索只能补充。
- GitHub 页面中的 Demo、截图和视频仍可能需要页面或媒体路线。
- 网站链接若最终下载 PDF 或打开视频，应切换到文档或媒体路线。
- 用户明确指定 Chrome、Browser 或其他可用工具时优先遵循；未指定时按材料与能力匹配，不固定某一浏览器。
- 登录态只在用户已授权的会话中使用，不新建账号或索取凭证。
- 明确的浏览器安全策略拒绝是停止条件：不得换浏览器表面、CDP、Computer Use、脚本或间接导航绕过。

## 覆盖状态

- **完整审阅**：匹配路线的关键验收项已经完成，可以对实际覆盖范围声明完整。
- **降级调查**：原材料因策略、登录、验证码、删除、地区、权限、格式或工具限制未完整检查；替代正文、搜索、转载和外部来源可以继续支撑调查，但不得冒充原材料完整审阅。

降级调查必须记录原材料缺口、替代证据、对结论的影响和仍需用户提供的材料。
