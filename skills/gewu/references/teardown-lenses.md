# 拆解视角索引

先识别对象，再选择最少但足够的视角。用户点名写作、设计、技术或商业时优先满足；不要为了模板完整而加载和输出所有维度。

| 用户目标 | 选择的详细视角 |
| --- | --- |
| 产品价值、技术真实性、源码、运行条件、采用、复刻、二开、许可与风险 | [lenses-product-technical.md](lenses-product-technical.md) |
| 网站体验、视觉交互、文章结构、写作风格、商业传播与增长 | [lenses-content-design-business.md](lenses-content-design-business.md) |

跨维度任务可以组合两个模块，但仍只保留会影响用户判断的内容。先说明对象的真实形态，再拆功能、实现或风格；没有源码或可运行入口时，不把概念、视频或静态演示描述成成品。
