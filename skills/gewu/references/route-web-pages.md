# 网站、文章与社交页面路线

适用于产品网站、在线工具、普通文章、博客、新闻、文档站、X/社交帖子和微信公众号文章。

## 通用页面

- 确认最终 URL、标题、主体、作者与日期
- 从顶部到有限页面底部，展开影响理解的内容
- 检查关键导航、标签页、图片、图表、视频、回复、引用和附件
- 打开会改变结论的官网、仓库、文档、定价、论文和原始来源
- 比对页面发布日期与项目当前状态

## 产品网站或在线工具

- 覆盖首页、核心功能、Demo/App、定价、FAQ、核心文档和代表性案例
- 区分真实可操作界面、录制演示、概念稿和营销合成图
- 确认账号、地区、付费、数据上传、隐私和集成门槛
- 不把“主要决策页面已覆盖”写成“遍历了整个域名”

## 普通文章、博客、新闻和文档

- 检查正文、脚注、引用、配图、附件和文末来源
- 区分事实、观点、案例、营销与作者推断
- 验证一手引用是否真的支持文章结论
- 需要写作拆解时检查标题、钩子、结构、节奏、论证和语气

## X、社交帖子和连续帖

- 检查主帖、连续帖、引用帖、作者补充、纠错和社区事实核查
- 检查每张关键图片、视频、附件和项目外链
- 记录实际查看的可见回复、作者回复和停止位置
- 社交流可能无限；未遍历无限内容时不得声称“全部回复”

## 微信公众号文章

- 检查标题、作者、公众号、发布时间和转载来源
- 从开头到文末检查正文、分节、重要配图和图中文字
- 检查嵌入视频、小程序、二维码、原文链接和相关阅读
- 检查文末声明、广告、版权和来源信息
- 对隐藏或省略的产品、网站、仓库和原发布启动来源反查

验证码、访问频率、登录、地区、权限或浏览器策略阻塞时，状态保持为“降级调查”。替代正文、转载、搜索与外部资料只能补充，不能冒充原页面视觉核验。

## 浏览器策略拒绝

若浏览器在页面载入前或操作过程中明确报告安全策略拒绝，例如 Browser Use 返回执行策略错误：

1. 保留准确错误和发生阶段。
2. 停止该动作，不换浏览器表面、CDP、Computer Use、脚本或间接导航绕过。
3. 记录当前可见范围为未完成。
4. 使用官方替代入口、公开存档或搜索做降级调查，或请用户提供 PDF、完整长截图、录屏等材料。

站点拒绝、扩展权限不足、未登录和浏览器执行策略是不同原因，不要统称为“浏览器打不开”。
