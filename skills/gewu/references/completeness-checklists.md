# 完整阅读与降级调查验收

“看到了正文”不等于“看完了页面”。在总体分析前完成适用检查项，明确当前是“完整审阅”还是“降级调查”，并在最终报告中给出覆盖单。

## 两种覆盖状态

### 完整审阅

匹配材料形态的关键验收项已经完成。这里的“完整”是对明确范围的完整，例如“文章主页面及 8 张关键配图”，不是对整个域名、所有历史评论或无限内容的无限承诺。

### 降级调查

原页面或材料因浏览器策略、登录、验证码、删除、地区、权限、格式或工具限制未完成检查。可以继续使用替代正文、转载、搜索、官方资料和外部证据，但必须同时说明：

- 原材料具体缺了什么
- 使用了哪些替代证据
- 缺口会不会改变结论
- 需要用户补充什么才能升级为完整审阅

不得把降级调查简写成“已看完”。

## 通用页面

- 确认最终 URL、页面标题、作者/主体与日期
- 从页面顶部浏览到有限页面底部
- 展开影响理解的“更多、全文、查看全部、继续阅读”
- 检查关键标签页、轮播、弹窗、菜单和交互状态
- 逐项检查影响结论的图片、图表、长图、二维码和附件
- 检查嵌入视频、音频或交互演示的真实可访问范围
- 打开所有会改变结论的官网、仓库、文档、定价、论文和原始来源链接
- 记录无法加载、需要登录、已删除或权限受限的项目

不要把导航栏、隐私政策、Cookie 设置和无关社交链接计入“关键外链”。

## 图片

- 分开记录检测到、成功渲染和实际目视检查的重要图片数
- 放大长图、信息图和产品截图，读取其中的文字与结构
- 对比图分别检查前后、左右或各版本
- 区分真实界面截图、概念稿、营销合成图和生成图
- 不用图片周围的说明代替图片本身

## 视频与音频

- 分开记录检测到、成功播放、完整检查、片段检查和只看封面的数量
- 内容影响结论时，检查媒体本身或可靠完整字幕
- 引用关键结论时附时间点或明确证据位置
- 无法播放、无字幕或受限时列为未验证

## 社交回复和无限内容

- 展开主帖连续内容、引用和作者补充
- 优先查看作者回复、纠错、反例和高信息量讨论
- 记录实际检查的可见回复数与作者回复数
- 无限滚动在连续多屏不再出现影响判断的新证据时可停止
- 用“已检查可见回复 N 条”而不是“看完所有评论”

## 多页面产品网站

至少覆盖直接影响判断的页面：

- 首页与核心功能页
- 定价或使用门槛
- Demo/App/登录入口
- 文档或帮助中心的核心工作流
- 案例、模板或输出示例
- 当版权、隐私或商业使用影响结论时，再看相应条款

把实际覆盖范围写清，不把“主要决策页面已覆盖”夸大成“整个域名所有页面已遍历”。

## 阅读覆盖单模板

```text
阅读覆盖
- 覆盖状态：完整审阅/降级调查
- 范围定义：本次声称完整或实际检查的明确边界
- 主页面：已/未从顶部到达底部
- 展开区域：检测 N，成功展开 N，目视检查 N
- 重要图片：检测 N，成功渲染 N，目视检查 N
- 视频/音频：检测 N，成功播放 N，完整 N，部分 N，只看封面 N
- 可见回复：检查 N 条，其中作者回复 N 条
- 关键外链：检测 N，已核验 N
- 主要子页面：列出实际页面
- 访问限制：无，或列出登录/验证码/策略拒绝/删除/权限等
- 替代证据：降级调查时列出
- 未验证项：列出会影响结论的剩余缺口
```

只有与目标相关且能可靠获取的计数才进入覆盖单。懒加载、隐藏轮播、重复 DOM 和无限内容可能使分母未知；此时写“已检查至页面底部”“已检查至第 N 条/某时间点”或其他位置边界，不编造 `N/N`。页面检测数不等于成功渲染数，成功渲染数也不等于实际目视检查数。
