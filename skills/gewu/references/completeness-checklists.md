# 完整阅读验收

“看到了正文”不等于“看完了页面”。在总体分析前完成适用检查项，在最终报告中给出覆盖单。

## 通用页面

- 确认最终 URL、页面标题、作者/主体与日期
- 从页面顶部浏览到有限页面底部
- 展开影响理解的“更多、全文、查看全部、继续阅读”
- 检查关键标签页、轮播、弹窗、菜单和交互状态
- 逐项检查影响结论的图片、图表、长图、二维码和附件
- 检查嵌入视频、音频或交互演示的真实可访问范围
- 打开所有会改变结论的官网、仓库、文档、定价、论文和原始来源链接
- 记录无法加载、需要登录、已删除或权限受限的项目

不要把导航栏、隐私政策、Cookie 设置和无关社交链接计入“关键外链”。

## 图片

- 记录页面重要图片总数与实际检查数
- 放大长图、信息图和产品截图，读取其中的文字与结构
- 对比图分别检查前后、左右或各版本
- 区分真实界面截图、概念稿、营销合成图和生成图
- 不用图片周围的说明代替图片本身

## 视频与音频

- 记录总数、已完整检查数和只看封面/片段的数量
- 内容影响结论时，检查媒体本身或可靠完整字幕
- 引用关键结论时附时间点或明确证据位置
- 无法播放、无字幕或受限时列为未验证

## 社交回复和无限内容

- 展开主帖连续内容、引用和作者补充
- 优先查看作者回复、纠错、反例和高信息量讨论
- 记录实际检查的可见回复数与作者回复数
- 无限滚动在连续多屏不再出现影响判断的新证据时可停止
- 用“已检查可见回复 N 条”而不是“看完所有评论”

## 多页面产品网站

至少覆盖直接影响判断的页面：

- 首页与核心功能页
- 定价或使用门槛
- Demo/App/登录入口
- 文档或帮助中心的核心工作流
- 案例、模板或输出示例
- 当版权、隐私或商业使用影响结论时，再看相应条款

把实际覆盖范围写清，不把“主要决策页面已覆盖”夸大成“整个域名所有页面已遍历”。

## 阅读覆盖单模板

```text
阅读覆盖
- 主页面：已/未从顶部到达底部
- 展开区域：已检查 N/N
- 重要图片：已检查 N/N
- 视频/音频：完整 N，部分 N，未检查 N
- 可见回复：检查 N 条，其中作者回复 N 条
- 关键外链：已核验 N/N
- 主要子页面：列出实际页面
- 访问限制：无，或列出登录/验证码/删除/权限等
- 未验证项：列出会影响结论的剩余缺口
```

只有与目标相关的计数才进入覆盖单。无法可靠计数时写“已检查至某位置/状态”，不要编造数字。
