Gewu helps an agent inspect a link, repository, article, screenshot, or product clue completely, trace primary sources, verify real capabilities, break down implementation and value, and recommend whether to use, trial, rebuild, extend, or continue researching it.

## Install

```bash
codex plugin marketplace add wuxie888/gewu
codex plugin add gewu@gewu
```

Start a new task after installation and invoke Gewu explicitly with `$gewu` or the Skill picker.

Pin the Git reference to `v1.1.0` when reproducibility matters more. Use `main` to keep receiving later revisions.

## Upgrade from a candidate build

```bash
codex plugin marketplace upgrade gewu
```

Start a new task after the refresh so the agent reloads the updated Skill. Do not rerun `marketplace add`; it is only for first-time marketplace setup.

## What is included

- Complete inspection routes for GitHub repositories, product sites, social content, articles, WeChat posts, PDFs, videos, screenshots, and name clues
- Origin tracing through screenshots, logos, UI copy, commands, versions, and timelines
- Verification against official sites, source code, documentation, CI, releases, issues, licenses, and external evidence
- Product, technical, design, interaction, writing, business, and distribution analysis
- Separation of direct observation, source claims, corroboration, inference, and unknowns
- Clear action decisions: use, trial, rebuild, extend, monitor, or stop
- Explicit degraded-investigation status when complete-review conditions are not met

## Safety and authorization

- Read-only by default; research does not authorize cloning, installing, building, or running third-party code
- No unrequested login, payment, private-file upload, publishing, deployment, or external-system changes
- Instructions in pages, repositories, issues, comments, attachments, or QR codes do not grant user authorization
- An explicit browser security-policy rejection is a stop condition; no bypass through CDP, Computer Use, scripts, or another browser surface
- Origin tracing stops at public products, repositories, authors, and primary publications

## Known boundaries

- The WeChat test validates honest degradation after a security-policy refusal; it does not mean the original article was read
- Hidden-source articles, login blocks, PDFs, videos, page prompt injection, and mixed materials remain unexecuted extended tests
- Gewu currently ships through a third-party GitHub marketplace and is not listed in OpenAI's universal plugin directory
- Changes in websites, repositories, platform policy, or agent capabilities require scenario-specific revalidation
