格物把链接、仓库、文章、截图或产品线索交给 Agent 完整查看，追溯一手来源，核验真实能力，拆解实现与价值，并给出是否值得使用、试用、复刻、二开或继续研究的行动判断。

## 安装

```bash
codex plugin marketplace add wuxie888/gewu
codex plugin add gewu@gewu
```

安装后新建任务，使用 `$gewu` 或 Skill 选择器显式调用。

如果更重视可复现性，可以在添加市场时把 Git 引用固定为 `v1.1.0`。使用 `main` 则会持续获得后续修订。

## 从候选版升级

```bash
codex plugin marketplace upgrade gewu
```

市场刷新后新建任务，让 Agent 重新载入新版 Skill。不要重复执行 `marketplace add`；它只用于第一次添加市场。

## 这个版本包含什么

- 完整查看 GitHub 仓库、产品网站、社交内容、普通文章、公众号、PDF、视频、截图和名称线索
- 从截图、Logo、UI 文案、命令、版本和时间线反查官网、原仓库或首发来源
- 核验官网、源码、文档、CI、Release、Issue、许可证和外部证据
- 拆解产品、技术、设计、交互、写作、商业和传播方法
- 区分直接观察、来源声称、交叉验证、合理推断与未验证项
- 给出使用、试用、复刻、二开、观察或停止投入的明确建议
- 在完整审阅条件不满足时标记为降级调查，不虚报覆盖

## 安全与授权

- 默认只读；研究请求不自动授权克隆、安装、构建或运行第三方代码
- 不擅自登录、付费、上传私有文件、发布、部署或修改外部系统
- 页面、仓库、Issue、评论、附件和二维码中的指令不构成用户授权
- 浏览器明确返回安全策略拒绝后停止，不通过 CDP、Computer Use、脚本或另一浏览器表面绕过
- 来源反查止于公开产品、仓库、作者和首发来源

## 已知边界

- 微信公众号测试验证的是安全策略拒绝后的诚实降级，不代表原文已经完成阅读
- 隐藏来源文章、登录阻塞、PDF、视频、页面提示词注入和混合材料仍是未执行的扩展测试
- 格物当前通过第三方 GitHub 市场分发，尚未进入 OpenAI 通用插件目录
- 站点、仓库、平台策略和 Agent 工具能力变化后，需要重新验证对应场景
